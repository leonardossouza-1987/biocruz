# Biocruz - Engenharia de Dados

Site institucional ficticio - Projeto Integrador Front-End.

## Tecnologias
- HTML5 semantico
- CSS3 (variaveis, grid, flexbox, media queries)
- JavaScript ES6+ (sem bibliotecas)
- SVG inline

## Paginas
- index.html - Home com carrossel e servicos
- sobre.html - Historia, missao e FAQ
- projetos.html - Portfolio com filtro
- contato.html - Formulario validado

## Funcionalidades JS
1. Menu mobile
2. Carrossel (autoplay, setas, swipe, teclado)
3. Contador animado
4. Accordion
5. Filtro de projetos
6. Validacao de formulario

## Como executar
python3 -m http.server 8001
Acesse http://localhost:8001
